# Xiaomi Mi TV 55 (MiTV-MOOQ0, codename croods), Android TV 10 (SDK 29), firmware QTG3.200305.006.3270,
# MediaTek/MStar m7632, India region.
# Live TV app: com.mediatek.wwtv.tvcenter (HDMI, AV and tuner; its window blocks screencap).
# Stock launcher: com.google.android.tvlauncher (disabled by build-and-install.sh).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mi-tv-55-mooq0/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mi-tv-55-mooq0/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Kept on purpose: com.mediatek.* (TV input, hotkeys, factory hooks), mitv.service (Xiaomi picture,
# sound and power service, persistent system uid), com.mitv.tvlock (parental lock),
# com.xiaomi.android.tvsetup.partnercustomizer (Bluetooth remote pairing), Gboard (Wi-Fi passwords).
#
# Notes from this firmware:
# - Live TV can't be disabled even if you never use the tuner: its TurnkeyUiMainActivity is also the
#   window that shows HDMI and AV. Hide it in the launcher (hidden_apps, empty live_tv_package) instead.
# - com.mediatek.wwtv.setupwizard is the whole first-boot flow (region, terms), not just the channel
#   scan, and isn't resident, so it stays.
# - screencap returns an empty file while Live TV is in front; press Home first.
# - After power-on the TV returns to the last source, not the launcher.
# - Before disabling com.mitv.dream, point the screensaver elsewhere, e.g.
#   settings put secure screensaver_components com.gathin.tvhome/.ClockDream
# - The "Minimal mode" section at the end is a "dumb TV + YouTube" setup; skip it for a normal debloat.
# - Ran fine through several reboots; no crashes in logcat -b crash.
