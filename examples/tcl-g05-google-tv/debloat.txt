# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g05-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g05-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh, the default is wrong here).
# Live TV app: com.tcl.tv (keep it, it also owns HDMI/antenna playback). Keep com.tcl.tvinput,
# com.tcl.suspension (input menu), com.tcl.dashboard, com.tcl.settings, com.tcl.system.server,
# com.tcl.keyhelp, com.tcl.autopair, com.tcl.tcl_bt_rcu_service (remote) and com.tcl.providers.config.
# Unlike the G10, com.tcl.ttvs ships enabled here; it carries TCL's BI analytics service.
#
# Known quirk, read before replacing the launcher:
# - Do NOT just disable launcherx here. com.google.android.tungsten.setupwraith/.RecoveryActivity
#   claims HOME at priority 1, which beats any third-party launcher's preferred-home setting, so
#   Home lands on a black, looping recovery screen. Shell cannot disable that component, and
#   after disabling the whole setupwraith package the TV rebooted with it back in charge.
#   Recover with: pm enable com.google.android.apps.tv.launcherx; pm enable com.google.android.tungsten.setupwraith
# - What works instead: leave launcherx enabled and let the launcher's HomeKeyService (an
#   accessibility service) switch to it whenever launcherx comes to the front. TCL handles the Home
#   key before accessibility sees it, so the switch happens on the window change, ~0.3 s after Home.
#   TCL's TclAppBoot blocks background service starts without its APP_AUTO_START app-op, so grant it
#   and flush app-ops to disk (a plain `reboot` skips the write):
#     appops set com.gathin.tvhome APP_AUTO_START allow; cmd appops write-settings
#     settings put secure enabled_accessibility_services com.gathin.tvhome/com.gathin.tvhome.HomeKeyService
#   Install the APK with pm install only; launcher/build-and-install.sh would disable launcherx.
#   Undo: settings delete secure enabled_accessibility_services
